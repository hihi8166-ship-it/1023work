# 무신사카피

무신사 기업 홈페이지와 상단 메뉴의 연결 페이지를 재현한 로컬 프로젝트입니다.
기존 랜딩 페이지를 유지하며 브랜드명은 **무신사카피 / MUSINSACOPY**로 변경했습니다.

## 실행

VS Code에서 `index.html`을 **Open with Live Server**로 열어 주세요. 현재 설정 포트는 **5503**입니다.
또는 프로젝트 폴더에서 `python -m http.server 8080`을 실행하고 `http://localhost:8080`에 접속합니다.
API 데이터를 로컬 JSON으로 읽으므로 HTTP 서버로 실행해야 합니다.

## 파일

- `index.html`: 원본 구조를 유지한 초기 문서
- `css/style.css`: 변경된 브랜드 로고의 크기 조정
- `js/main.js`: 로컬 데이터 연결, 독립 페이지 이동, 뉴스 검색·태그 이동
- `js/career.js`: 채용 필터, FAQ, 모바일 메뉴, 지원 링크 연결
- `company/`, `business/`, `impact/`: 상단 메뉴의 독립 페이지
- `newsroom/`: 보도자료·팀무신사카피·공지사항·알려드립니다 및 기사 상세
- `career/`: 채용 메인·복리후생·FAQ·팀 소개·공고 상세
- `_next/`: 원본의 반응형 스타일 및 슬라이더·스크롤·메뉴 런타임
- `data/`: 2026-10-23에 확인한 배너·연혁·사업·뉴스·리포트 데이터
- `assets/`: 로컬 이미지 및 변경한 로고
- `.qa/`: 브라우저 비교 화면 및 검사 기록

`python validate.py`로 정적 파일 누락을 확인할 수 있습니다.

## 구현 범위

- Company: 기업 소개, 가치, 전체 연혁, 변경한 로고 SVG 다운로드
- Business: 배경 영상, 성장 지표, 온라인·오프라인·글로벌·브랜드·인프라 탭
- Impact: 활동별 이동, 지역사회·지속가능성, 리포트 안내
- Newsroom: 보도자료 1,312건 검색·태그·페이지 이동, 전체 뉴스 상세 1,449개
- Career: 공고 101개와 상세 내용, 조건별 필터, 복리후생, FAQ, TECH·COMMERCE·29CM 팀 소개
- 데스크톱·모바일 메뉴 및 각 페이지 간 이동

## 확인 및 외부 연결

`python validate.py`는 HTML과 CSS가 참조하는 로컬 파일 및 캐시 데이터의 누락을 검사합니다.
실제 Chrome의 검사 결과와 스크린샷은 `.qa/`에 저장됩니다.

실제 지원서 제출, SNS·스토어·보고서 원문과 다국어 화면은 원본 서비스로 연결합니다.
한국어 페이지와 데이터는 로컬에 저장되어 있지만, 일부 과거 기사 이미지는 원본 CDN을 사용하므로 인터넷 연결이 필요합니다.
자료는 저장 시점의 스냅샷이며 자동 갱신 기능은 없습니다.

`prepare.ps1`은 초기 단일 페이지 작업의 기록입니다. 최종 사이트 실행에는 필요하지 않습니다.
